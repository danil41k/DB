# Опис предметної області

Спортивний клуб потребує автоматизованої системи для зберігання та обробки інформації про учасників, тренерів, абонементи та тренування. Розроблена система дозволяє вести облік клієнтів, контролювати відвідування занять, зберігати інформацію про спортивне обладнання та організовувати роботу клубу в єдиному інформаційному середовищі.

Основними об’єктами системи є учасники клубу, тренери, абонементи, тренувальні заняття та спортивне обладнання. Між ними реалізовані логічні зв’язки, що забезпечують цілісність та узгодженість даних.

# Логічна схема

База даних складається з таких таблиць:

## members

Зберігає інформацію про учасників клубу.

## trainers

Містить дані про тренерів та їх спеціалізацію.

## memberships

Зберігає інформацію про види абонементів.

## member_memberships

Реалізує зв'язок між учасниками та їх абонементами.

## training_sessions

Містить інформацію про тренування.

## attendance

Зберігає інформацію про відвідування тренувань учасниками.

## equipment

Містить відомості про спортивне обладнання.

## users

Таблиця користувачів системи.

## activity_log

Призначена для логування дій користувачів.

## member_audit

Зберігає історію змін, пов’язаних з учасниками клубу.

Усі таблиці приведені до третьої нормальної форми.

# Налаштування Docker

Для запуску PostgreSQL використано Docker Compose.

Запуск контейнерів виконується командою:

```bash
docker compose up -d
```

Перевірка роботи контейнерів:

```bash
docker ps
```

Доступ до pgAdmin:

```text
http://localhost:5050
```

# SQL-запити

Було реалізовано набір SQL-запитів різної складності.

### Простий запит

Виведення списку всіх учасників клубу.

### Запит з JOIN

Отримання інформації про учасників та їх абонементи.

### Агрегатний запит

Отримання кількості тренувань для кожного тренера.

### Запит із підзапитом

Отримання тренувань з кількістю учасників вище середнього значення.

### Запит із декількома JOIN

Отримання інформації про відвідування тренувань.

# Висновок

У результаті виконання лабораторної роботи була розроблена реляційна база даних для системи управління спортивним клубом. Для роботи з базою даних було створено консольний застосунок мовою Python та вебзастосунок на Flask. Також були реалізовані тригери, процедури, представлення, REST API та система журналювання подій. Виконана робота дозволила отримати практичні навички проєктування баз даних та їх інтеграції з програмними застосунками.
